Person marker. Colour identity is the backbone of Tally — the same person is the same hue everywhere in the app.

```jsx
<Avatar name="Mei Wong" hue={4} size={40} selected />
<Avatar name="Sam" hue={2} dimmed />
```

No photos in the system — initials on a person hue only. Toggle `selected`/`dimmed` to show inclusion in a split; that pair is the core interaction of the Add Expense screen.
